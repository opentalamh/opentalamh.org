# opentalamh.org

Redirects every opentalamh.org address to the same page on [opentalamh.ie](https://opentalamh.ie).

GitHub Pages serves `index.html` for the home page and `404.html` for every other path, and both forward to opentalamh.ie with the path, query and anchor kept. The site's own source is in [opentalamh/opentalamh.ie](https://github.com/opentalamh/opentalamh.ie).

DNS for opentalamh.org (Blacknight): four A records for `@` pointing to 185.199.108.153, 185.199.109.153, 185.199.110.153 and 185.199.111.153, and a CNAME for `www` pointing to opentalamh.github.io.
